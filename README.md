One funny line of text, 1 to 140 characters, short enough to read in a breath and whole enough to land on its own — judged pairwise by an AI comedy editor on the laugh first, then the turn, the tightness, the freshness and the clarity. Free to enter, $2 shared by the top 10 lines.

This entry sends one line: a smart speaker asked for relaxing music that answers by reading unread emails aloud — the calm you asked for, delivered as the exact opposite.

## Run it

```sh
python3 main.py
```

The program writes exactly that one line (87 characters) to `/output/entry.txt`. Pure Python standard library, deterministic: no input, no randomness, no clock, no network.
